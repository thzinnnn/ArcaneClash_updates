# ArcanaClash Updates

Canal público oficial de atualizações do **ArcanaClash**.

Este repositório **não contém o código-fonte do jogo**. Ele serve apenas para distribuir metadados de versão, checksums e pacotes compilados publicados em GitHub Releases.

O projeto principal permanece privado em `thzinnnn/ArcanaClash`.

## Conteúdo público esperado

- `version.json` — versão estável e changelog.
- `ArcanaClash.sha256` — checksum da release atual, quando publicado.
- GitHub Releases — APK oficial assinado e seu checksum.

Não devem ser publicados aqui chaves de assinatura, senhas, tokens, source maps ou arquivos-fonte do jogo.
